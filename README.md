# 라벨 편집기 (웹)

판매자에게 받은 라벨 파일(`…_라벨편집기.html`)을 아이패드·아이폰·PC의 브라우저에서 열어
내용을 고치고 라벨지에 인쇄하는 페이지입니다.

- 주소: https://eunskang0-boop.github.io/label-editor/
- 사용법: 사파리(또는 크롬)로 주소를 열고 **라벨 파일 열기** → 받은 파일을 고르세요.
- 파일은 기기 안에서만 열리며 서버로 전송되지 않습니다. 입력한 내용은 그 기기의 브라우저에 저장됩니다.

이 저장소에는 빈 편집기 페이지만 있고, 고객 데이터나 디자인 원본은 들어 있지 않습니다.
