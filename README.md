# 라벨 편집기 (웹)

판매자에게 받은 라벨 파일(`…_라벨편집기.html`)을 PC · 태블릿의 브라우저에서 열어
내용을 고치고 라벨지에 인쇄하는 페이지입니다.

- 주소: https://eunskang0-boop.github.io/label-editor/
- 사용법: 사파리(또는 크롬)로 주소를 열고 **라벨 파일 열기** → 받은 파일을 고르세요.
- 파일은 기기 안에서만 열리며 서버로 전송되지 않습니다. 입력한 내용은 그 기기의 브라우저에 저장됩니다.

## 바로 써 보는 샘플

주소만 열면 파일 없이 바로 열리는 샘플 편집기입니다.

- DELUXE (기본 도구 8가지): https://eunskang0-boop.github.io/label-editor/deluxe/
- PREMIUM (전체 도구 12가지): https://eunskang0-boop.github.io/label-editor/premium/
- B2B (연구소·제조사): https://eunskang0-boop.github.io/label-editor/b2b/

이 저장소에는 빈 편집기 페이지와 샘플만 있고, 고객 데이터나 디자인 원본은 들어 있지 않습니다.
